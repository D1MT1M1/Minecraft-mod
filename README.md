# 🎰 Psycho-Roulette (Fabric — Minecraft 26.3)

Мод для Minecraft **26.3 (Fabric)**, который каждые **5 минут** крутит рулетку и выдает игроку одно из **20 психических заболеваний** — со своим геймплеем, звуками, баффами, дебаффами и HUD-панелью.

## 🧠 Все 20 заболеваний в моде
1. **Пиромания** — Скорость II + Сила II рядом с огнём, ломка без поджогов.
2. **Мегаломания** — Сила II + Сопротивление I, но выкидывает щиты, брезгует дешёвой едой и бьёт за побег спиной.
3. **Клептомания** — Автоматически ворует предметы из ближайших сундуков/бочек и карманов жителей.
4. **Синдром Туретта** — Случайные тики: выброс предмета, прыжки, взмахи, резкий поворот и крики, агрящие мобов в 32 блоках.
5. **Нарколепсия** — Внезапные отрубания на 3 секунды в самый неподходящий момент.
6. **Агорафобия** — Паника под открытым небом, спокойствие и реген под крышей.
7. **Клаустрофобия** — Удушье и тошнота в узких тоннелях с низким потолком.
8. **Галлюцинации** — Фейковые шипения криперов, взрывы без урона, звуки сундуков и газлайтинг в чат.
9. **Социофобия** — Паническая атака и отталкивание от любого живого существа рядом.
10. **Акрофобия** — Головокружение и слабость возле обрывов.
11. **Гидрофобия** — Вода и дождь обжигают тебя, как Эндермена.
12. **Никтофобия** — Темнота ранит тебя; на свету — бафф скорости.
13. **Жёсткое ОКР** — Навязчивый ритуал (присядь 3 раза) и дискомфорт от нечётных стаков в руке.
14. **Биполярка** — Каждые 30 секунд качели: Мания (бог, но скрыто ХП) ↔ Апатия.
15. **Паранойя** — Нужно постоянно оглядываться назад, иначе накроет ужас.
16. **Компульсивное обжорство** — Бешеный расход голода, но полная сытость даёт Скорость II и Силу I.
17. **Синдром Плюшкина** — Чем больше забит инвентарь, тем ты сильнее; потеря вещей наносит урон.
18. **Амнезия** — Перемешивает хотбар и разворачивает камеру на 180°.
19. **Дромомания** — Нельзя стоять на месте дольше 2 секунд; пока бежишь — Скорость II + Прыгучесть.
20. **Берсерк-психоз** — Удары по мобам дают Силу III + Реген II; без драки 20 сек начинается ломка.

## ✨ Дополнительные фишки
- **HUD-виджет** в правом верхнем углу с таймером, прогресс-баром и статусом симптомов.
- **Скрытый диагноз `???`** (шанс 12% — угадывай сам по симптомам).
- **Обострение x2** (в грозу и полнолуние выпадают сразу 2 диагноза).
- **Награды за выживание цикла** + крафты: **Таблетка от всего** (`miracle_pill`) и **Жетон Реролла** (`reroll_token`).
- **Команды для теста:**
  - `/psychoroulette roll` — прокрутить рулетку прямо сейчас
  - `/psychoroulette combo` — запустить Обострение x2
  - `/psychoroulette set <id>` — выдать конкретный диагноз (с автодополнением)
  - `/psychoroulette interval <секунды>` — сменить длительность цикла (например, `30` для быстрого теста)
  - `/psychoroulette calm` — включить режим спокойствия
  - `/psychoroulette list` — список всех 20 ID

## 🛠️ Как собрать готовый `.jar` за 2 минуты

### Вариант 1: Автосборка через GitHub Actions (без установки Java и Gradle)
1. Создай любой репозиторий на GitHub и залей туда все файлы из архива.
2. *(Важно для 26.3)* Зайди на **https://fabricmc.net/develop/**, выбери **26.3** и при необходимости обнови 3 строки в `gradle.properties` (`loader_version`, `loom_version`, `fabric_version`), чтобы совпали с актуальным патчем Fabric API для 26.3.
3. Перейди во вкладку **Actions** → **Build Psycho-Roulette JAR** → скачай готовый `.jar` из раздела **Artifacts**.
4. Закинь `.jar` вместе с `fabric-api` в папку `.minecraft/mods/`.

### Вариант 2: Локально
1. Установи **JDK 25** (Adoptium Temurin 25) и **Gradle 9.2+**.
2. В папке проекта выполни:
   ```bash
   gradle build
   ```
3. Готовый мод появится в `build/libs/psycho-roulette-1.0.0+mc26.3.jar`.
